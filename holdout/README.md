# Holdout probes

This directory is intentionally empty in the public repo (see .gitignore).

It holds the unpublished sibling of every standing probe in
themes/THEMES.md: semantically parallel phrasings that never appear
online. Each monthly Compare step reports convergence separately for
published vs holdout probes; faster convergence on published probes is
the signature of the observatory's own vocabulary colonizing later
models.

Rules:
- One holdout variant per theme, minimum.
- A holdout probe is "burned" the moment it appears in any published
  artifact, digest, or commit. Burned probes are retired and replaced.
- Back this folder up outside git. Losing it breaks the longitudinal
  comparison.
