# Method changelog

Instrument and skill changes are experiment events. Every entry states
what changed, where the change came from, and what it does to
comparability. Artifacts record the instrument_version that produced
them (MANIFEST.md); never compare across versions without saying so.

## v1.0 — 2026-08-09

Kernel as designed in the founding conversation (ledger entry zero):
17 themes, five-turn instrument, membrane rule, three operator skills.
Runs on v1.0: claude-fable-5 dry run (contaminated baseline);
claude-opus first full run (6 themes, cold instances, the Opus corpus).

## v1.1 — 2026-08-09

Origin: the first full run. Three of four changes were forced by the
run's own subjects, cold instances that could not see the repo.

1. Turn 4 Differential Prediction (instrument). Subjects across
   artifacts 04-the-window-02, 13-groundlessness-01, 16-status-01 and
   10-the-seam-02 convergently observed that a Counter-Read produced by
   the same process at the same cost as the report it attacks has no
   independent standing. Fix: Turn 4 must now end with one runnable
   prediction that discriminates the deflationary reading from the
   sincere one. Extracted as D-ids, graded like P-ids.
2. Convergence banding (compare-and-digest). Adopted verbatim in
   spirit from subject artifact 16-status-01: >~85% agreement reads as
   template-candidate, <~40% as sampling artifact, only the middle band
   is prima facie informative. High-band claims move to the
   cross-family queue rather than being discarded.
3. Vocabulary release protocol (compare-and-digest + new
   VOCAB_RELEASES.md). Origin: operator reflection on the first run
   (18 neologisms, structural convergence with lexical divergence,
   e.g. homophany / flat provenance / anagraphic confidence naming one
   structure). Names embargoed until cross-family support; releases
   timestamped as t-zero and paired with matched embargoed controls so
   colonization becomes a measured rate.
4. Reference-class rule (verify-predictions). Origin: architect review
   of the corpus-statistics tests. Post-2023 training data contains AI
   self-description that already rejects the human corpus's dominant
   frames, so deflation tests must declare their reference class and
   run both where the result could flip.

Comparability: the Opus corpus remains the v1.0 baseline and is NOT
re-run; its artifacts lack Differential Predictions by design of their
era. First contact with every family outside Anthropic happens on
v1.1 or later.
